Instruction for students answering quiz questions

For Students — Answering a Question
  1. Open the quiz question. You see the starting tree provided by the teacher.
  2. Syntactic Functions: If the Syntactic Functions Window appears above the tree, enter the required function (e.g., Subject, Predicate) for each listed phrase.
  3. Build and edit your syntax tree using the Editing and Navigation controls described in the sections below.
💡
Connectivity Warning: If you see a yellow warning bar at the top, it means your tree is not fully connected. Make sure all nodes belong to one single root before finishing.
Editing Features
  • ✏️
    Rename: Double-click (or long press) any node to edit its label. For leaves, you can also edit the word.
  • ↑
    Add Parent: Select a node and click the up arrow to insert a node above it.
  • ↓
    Add Child: Select a node and click the down arrow to add a node below it.
  • ✕
    Delete: Click the red X to remove a node. You can choose to keep or delete its children.
Navigation & Control
  • 🖐
    Pan/Zoom: Drag the background to move. Use buttons or pinch to zoom on touch screens.
  • 🔍
    Navigation Panel (Bottom-Right):
    • / to Undo / Redo.
    • + / - to Zoom.
    • 1:1 to Reset scale.
    • ⌖ to Center (or double-click background).
  • ⌨
    Shortcuts: Ctrl + Scroll (Zoom at cursor), Ctrl+Z (Undo), Ctrl+Y (Redo), Ctrl+0 (Reset).
  • ↕
    Collapse UI: Click the ▲ or ▼ toggle in the top-right corner to hide/show toolbars for more drawing space.
  • 🔵
    Edge Scrolling: Drag a node to the screen edge to auto-scroll the view.
